# Instrucciones para Correr el Proyecto IoT

Sigue estos pasos para levantar el sistema en tu máquina local:

## 1. Requisitos
*   Docker y Docker Compose instalados.
*   Java 8 o superior (para la GUI del Operador).

## 2. Levantar los Servicios (Backend + Web)
Desde la raíz del proyecto (`telematica-p1`), ejecuta:
```bash
docker-compose up --build -d
```
Esto encenderá:
*   Servidor IoT (C) en puerto 9000
*   Servicio de Identidad en puerto 5001
*   Dashboard Web en puerto 5000
*   Sensores simulados

## 3. Acceso al Dashboard Web
Abre en tu navegador: `http://localhost:5000`
*   **Usuario:** `admin` | **Clave:** `admin123`
*   **Usuario:** `operador` | **Clave:** `operador123`

## 4. Correr la GUI del Operador (Java)
Entra a la carpeta `operador_gui` y compila/ejecuta:
```bash
javac -source 1.8 -target 1.8 -d out src\operatorgui\*.java
java -cp out operatorgui.OperatorMain localhost 9000 admin_operador
```

## 5. Notas Importantes
*   **AWS:** Si quieres conectarte al servidor en la nube, cambia `localhost` por la IP de la instancia en el comando de Java.
*   **Logs:** Los logs del servidor C se guardan en la carpeta `servidor/logs`.
